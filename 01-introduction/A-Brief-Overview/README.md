# Node.js Course Overview

## What is it?

Node.js is a **JavaScript runtime environment** that allows JavaScript to run **outside the browser**.

It uses Google's **V8 JavaScript engine** to execute JavaScript.

## How it works

* Browser → JavaScript runs in the browser environment.
* Node.js → JavaScript runs outside the browser.
* Node.js provides additional APIs that allow JavaScript to interact with the system and handle server-side tasks.

## Why Node.js?

* Allows JavaScript to be used for **server-side development**.
* Makes it possible to use JavaScript across both the frontend and backend.
* Useful for building **real-time and data-intensive applications**.
* Familiar JavaScript syntax makes the transition easier for JavaScript developers.

## Important Points

* **JavaScript** = programming language
* **V8** = JavaScript engine used by Node.js
* **Node.js** = runtime environment for executing JavaScript outside the browser
* Node.js is **not a framework**.

## Common Mistakes

* ❌ Node.js is a programming language.
* ❌ Node.js is a framework.
* ❌ Node.js replaces browser JavaScript.
* ❌ Node.js automatically makes every application lightweight or simple.

## Key Takeaways

* Node.js lets JavaScript run outside the browser.
* It enables JavaScript to be used for backend/server-side development.
* Knowing JavaScript gives you a strong foundation for learning Node.js.
* A full-stack application can use JavaScript in both the browser and the Node.js server.
