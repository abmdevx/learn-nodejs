# Learn Node.js 🚀

This repository documents my journey of learning **Node.js** from beginner to advanced concepts.

I'm learning Node.js through **Educative.io** and using this repository to track my progress, notes, diagrams, coding exercises, examples, and projects.

## 🎯 Goal

The goal is not to create perfect notes.

The goal is to **actually learn Node.js by understanding, recalling, explaining, and writing code**.

---

## 🧠 Learning Workflow

For every important lesson, I follow:

**Learn → Quiz → Explain → Notes → Practice → Move On**

### 1. Learn

Complete the Educative lesson first and try to understand it before using AI.

### 2. Quiz

Test my understanding with questions based on the lesson.

### 3. Explain

Explain the concept in my own words and identify anything I misunderstood or missed.

### 4. Notes

Create concise Markdown notes for future reference.

Notes focus on:

- Important concepts
- Definitions
- Examples
- Common mistakes
- Key takeaways

### 5. Practice

Write code and solve exercises based on what I have learned.

### 6. Move On

Before moving to the next lesson, I should be able to:

- Explain the concept without looking at my notes
- Explain why it is useful
- Write a small example from scratch
- Answer basic questions about it
- Identify at least one common mistake or limitation

If I can't do these, I review the lesson before moving forward.
